### 🔎 [Network Intrusion Detection System — BSc thesis](https://github.com/Rahmi-serag/machine-learning-ids)

A Python-based, flow-level intrusion detection research prototype built around the CICIDS2017 dataset. I trained and compared **Random Forest, Decision Tree, linear SVM, and neural-network classifiers** and developed an experimental **PCAP → CICFlowMeter → model inference → results** workflow using traffic from a controlled virtual lab.

- **Stack:** Python, scikit-learn, pandas, Linux, Wireshark, CICFlowMeter, Docker.
- **Reported result:** Random Forest reached **99.69% F1** on the project's baseline test split. The repository documents sampling, setup requirements, and evaluation limitations; this is not a production-detection guarantee.
- [Explore the code, results, and architecture](https://github.com/Rahmi-serag/machine-learning-ids)
